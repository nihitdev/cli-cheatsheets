# cli-cheatsheets

Quick, practical, copy-paste-friendly cheatsheets for the command-line tools I use.

No giant tutorials. No unnecessary explanation.

Just:

```text
command
→ what it does
```

## Philosophy

These aren't complete manuals.

They're for the moment when you know a command exists but your brain goes:

```text
wait... what were the flags again?
```

## Contributing

Found a useful command?

Add it to the relevant cheatsheet and open a pull request.

Keep additions:

- short
- useful
- easy to copy
- easy to understand
